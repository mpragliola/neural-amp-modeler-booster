🎸 NAM Profile Booster

What is NAM?

NAM (Neural Amp Modeler) is a guitar amp modeling software that uses a neural network to learn and emulate amplifiers and effects. It's open source and free. NAM profiles are .nam files containing the settings and parameters for these emulations.

What does this do?

NAM profiles carry metadata about loudness, but some readers ignore it, making profiles sound quiet. This tool boosts the output level directly on the neural network weights — supports both legacy (A1) and A2 / SlimmableContainer formats.
